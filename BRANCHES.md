# Branches

faBolusGarmin moves with faBolus and TandemKit. The branch and the tags are described once, in faBolus's
[`BRANCHES.md`](https://github.com/faBolus-app/faBolus/blob/main/BRANCHES.md).

In short: `main` is the only branch, and the watch app on it is for the phone app on faBolus's `main`;
build the two from the same branch or release tag. `v0.4.0` is the first release of the rebuilt app.
`v1-final` tags the watch app for the earlier phone app (the two versions don't talk to each other), and
`archive/*` tags keep the deleted side branches, among them other devices (`archive/dev/garmin-devices`)
and a watch face (`archive/experimental/2026-08-27`).
